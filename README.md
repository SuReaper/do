1. Run ``git clone https://github.com/SuReaper/do.git && cd do``
2. Open CMD/Git Bash and run: ``npx wrangler@latest deploy --temporary`` (with temporary you can deploy it anonymously for 60mins)
3. Open the link.

NOTES:
- Make sure to have the app installed.
- Open the link inside of an android phone's browser and then click on Open PoC.
- The POC Page is at /poc, for direct testing.
- Logs are located at /logs?poclogs. Check them for more detailed info.
